security Data Privacy Policy

1. Overview

FileTools is a local desktop/web application. All file processing happens entirely on your machine. No data is transmitted to external servers.

2. Data Processing

  • File content: Files are processed in-memory or via temporary files on your local system. No file data leaves your machine.
  • Hash values: xxHash3-128 digests are computed locally for directory comparison and deduplication. These hashes are stored in a temporary local database to speed up subsequent scans.
  • Local storage: The application uses your browser’s localStorage to remember UI preferences (e.g. last-used directories). This data never leaves your device.

3. No Cookies or Tracking

This application does not use cookies, analytics, tracking pixels, or any form of user tracking. There is no advertising.

4. Third-Party Services

This application does not use any third-party services. All assets, including the Roboto font and Material Icons, are bundled locally. No requests are made to external servers.

5. Your Rights

Since no personal data is collected or stored by this application beyond what resides on your own machine, the typical data-subject rights (access, rectification, deletion) are inherently fulfilled — you have full control over all data at all times.

If you have questions about data privacy, please reach out via GitHub.
